# Executive Sales & Profit Analytics Dashboard

## Overview
Interactive Tableau dashboard built during the ITI Data Analysis
Program to deliver actionable sales and profit insights.

## Features
- Executive KPI cards (Total Profit, Price, Avg. Profit Margin)
- Dual-axis chart: Sales vs. Profit over time
- Dynamic parameters (Sales Target, Top N Products)
- Wildcard match filters for product drill-down
- Lollipop chart for category performance
- Dashboard navigation objects

## Tools
Tableau, Calculated Fields, Parameters
